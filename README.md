# 本丸刀帐

刀剣乱舞 ONLINE 的刀帐收集记录网页。

## 功能

- **刀帐**：记录每把刀的入手、极化、入手日期、备注，以及立绘解锁情况；可按刀种、刀派、状态筛选和搜索。
- **限时锻刀计算**：根据手头资源、依頼札、御札和天井点数，计算能锻几次、拿到的概率。
- **锻刀模拟**：按玩家统计的出现率随机模拟普通锻刀和限时锻刀。
- **存档**：登录后通过 Supabase 在不同设备间同步，也可以导出 / 导入备份。

## 文件

- `index.html`：整个网页，单文件，直接用浏览器打开即可。

## 说明

网页里的 Supabase 密钥是 publishable（公开）密钥，本来就会出现在浏览器里，可以放在仓库中；每个人只能读写自己的记录，靠的是数据库的访问规则（RLS）。service_role 密钥不要放进仓库。
